================================================================================
  QUICK START (3 STEPS)
================================================================================

1. Open Command Prompt (Win + R, type "cmd", press Enter)

2. Navigate to portfolio:
   cd "z:\projects\new portifolio\portfolio"

3. Start the server:
   npm start

   OR just double-click: start.bat

Your portfolio will open at: http://localhost:3000
